## Files Modified

### src/types.ts

Added section 8 (Warehouse) with `Warehouse` and `WarehouseStock` interfaces.

### src/services/warehouseService.ts

Complete rewrite. Replaced old `StockLocation`/`StockMovement` types and `setStockLocation`/`getStockLocation`/`recordStockMovement`/`checkLowStock` functions with Firestore-backed:

- `createWarehouse` -- addDoc to `warehouses` collection, unsets other defaults if `isDefault: true`
- `getWarehouses` -- query by sellerId, ordered by createdAt desc
- `updateWarehouse` -- updateDoc with timestamp, unsets other defaults if setting isDefault
- `deleteWarehouse` -- deletes warehouse + cascading delete of all warehouseStock docs
- `getDefaultWarehouse` -- query warehouses where isDefault == true
- `setWarehouseStock` -- setDoc at `warehouseStock/{warehouseId}_{productId}`
- `getWarehouseStock` -- query warehouseStock by productId
- `getTotalStock` -- sum quantities across warehouseStock for a product
- Internal `unsetOtherDefaults` helper

### src/services/stockMovementService.ts

- Added optional `warehouseId?: string` to `StockMovement` interface
- Added optional 7th parameter `warehouseId?: string` to `recordStockChange`, includes it in Firestore doc when provided

### src/services/productService.ts

- Added imports for `getTotalStock`, `getDefaultWarehouse`, `setWarehouseStock` from warehouseService
- Added `quantity` field to movements tracking array
- Updated `decreaseProductStock`: after transaction, checks if product has warehouse stock via `getTotalStock`. If so and a default warehouse exists, decrements the default warehouse's stock. Always decrements product.stock as before.
- Updated `restoreProductStock`: same pattern but increments instead of decrements.
- Both functions pass `warehouseId` to `recordStockChange` when available.
- **Function signatures unchanged** -- all existing callers (Checkout, orderService, returnService) continue working.

### src/pages/SellerInventory.tsx

- Added `Warehouse` import from lucide-react
- Added imports for `Warehouse`, `WarehouseStock` types and warehouseService functions
- Changed `activeTab` union type to include `'depolar'`
- Added warehouse state variables (warehouses, form, editing, loading, etc.)
- Added `Warehouse` icon to sidebar nav (4th position after analytics)
- Added "Depo Yonetimi" header title
- Added full Depolar tab content: warehouse list with cards, empty state, loading state, add/edit modal with form validation, delete confirmation
- Added stock allocation summary section
- Added useEffect to load warehouses when tab is active
- Added warehouse add/edit modal with form (name, address, city, state, postalCode, country, isDefault checkbox) and save/cancel actions
