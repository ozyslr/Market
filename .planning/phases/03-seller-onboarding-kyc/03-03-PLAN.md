    - check response.ok; check Content-Type starts with 'image/'; check arrayBuffer.byteLength <= 5*1024*1024

<threat_model>

## Trust Boundaries

| Boundary                                       | Description                                                                                       |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Seller browser → POST /api/products/csv-import | verifyFirebaseToken; sellerId from req.uid (not from payload)                                     |
| Server → external image URLs in CSV            | SSRF mitigation: private IP block, https-only (prod), 10s timeout, content-type + size validation |
| Server → Firestore batch write                 | Only after per-row Zod + category validation passes                                               |

## STRIDE Threat Register

| Threat ID | Category               | Component                                      | Disposition | Mitigation Plan                                                                                                                                                     |
| --------- | ---------------------- | ---------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-03-12   | Tampering              | SSRF via CSV image_url                         | mitigate    | Block private IP ranges (10.x, 192.168.x, 172.16-31.x, 127.x, 169.254.x) in fetchImageToStorage; require https: in prod; enforce content-type image/\* and max 5 MB |
| T-03-13   | Denial of Service      | Oversized CSV upload                           | mitigate    | 10 MB file size check before Papa.parse; response timeout on image fetch via AbortSignal.timeout(10_000)                                                            |
| T-03-14   | Tampering              | CSV category bypass — wrong commission tier    | mitigate    | platformCategorySet built from Firestore categories collection at import start; unknown category fails row                                                          |
| T-03-15   | Information Disclosure | Product export reveals other sellers' products | mitigate    | GET /api/products/csv-export queries where sellerId == req.uid; verifyFirebaseToken ensures uid is authentic                                                        |
| T-03-16   | Tampering              | Seller imports products with sellerId spoofed  | mitigate    | sellerId in Firestore batch write is always req.uid (from Firebase token), not from CSV or request body                                                             |
| T-03-SC   | Tampering              | npm/pip/cargo installs                         | accept      | No new packages installed — papaparse, zod, firebase-admin, native fetch all pre-existing                                                                           |

</threat_model>
