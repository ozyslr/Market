## Trust Boundaries

| Boundary                                          | Description                                                           |
| ------------------------------------------------- | --------------------------------------------------------------------- |
| Seller browser → Firebase Storage store-assets/\* | Authenticated write (request.auth != null in storage.rules)           |
| Seller browser → POST /api/v1/products            | API key auth; server validates images/category before Firestore write |
| Public browser → /store/:slug                     | Unauthenticated read; only public seller data returned                |

## STRIDE Threat Register

| Threat ID | Category               | Component                                        | Disposition | Mitigation Plan                                                                                                                                                 |
| --------- | ---------------------- | ------------------------------------------------ | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-03-08   | Tampering              | POST /api/v1/products — invalid product data     | mitigate    | Server-side validation: images.length >= 1, categoryId required, price > 0 returns 400 before Firestore write                                                   |
| T-03-09   | Tampering              | Slug injection — path traversal in /store/:slug  | mitigate    | Slug sanitized at submitApplication: slug.replace(/[^a-z0-9-]/g,'') before Firestore write (per RESEARCH.md Pitfall 8); uniqueness suffix appended if collision |

| T-03-11   | Tampering              | Logo/banner upload — oversized or non-image file | mitigate    | Client-side: validate type image/\* and max size (2 MB logo, 5 MB banner) before upload; Storage rules: allow write if request.auth != null                     |
