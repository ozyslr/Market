# Plan 13-01: Currency Infrastructure & Display

**Objective:** Create CurrencyContext, daily FX rate fetching from ECB, EUR/TRY display toggle, and per-country URL routing.

**Requirements:** CUR-01, CUR-02, CUR-03, CUR-06

## Tasks

### Task 1: Create CurrencyContext and FX Rate Service

<objective>
Create CurrencyContext provider for app-wide currency state (active currency + FX rates) and FxRateService for fetching and caching ECB exchange rates in Firestore.
</objective>

<read_first>

- src/context/LanguageContext.tsx (existing context pattern to follow)
- src/context/AuthContext.tsx (provider pattern with Firebase)
- src/services/productService.ts (Firestore read/write patterns)
- src/App.tsx (context provider nesting order)
  </read_first>

<action>
1. Create `src/context/CurrencyContext.tsx`:
   - State: `currency` ('TRY' | 'EUR'), `rates` (Record<string, number>), `lastUpdated` (Date | null)
   - `toggleCurrency()` — switches between TRY/EUR
   - `convertPrice(priceTRY: number): { display: number; currency: string; formatted: string }` — converts TRY base to active currency
   - `formatPrice(amount: number, currency?: string): string` — locale-aware formatting (TR: 1.234,56 ₺, EN: €12.34)
   - On mount: read `currency` from localStorage (persisted preference)
   - On currency change: persist to localStorage
   - Geo-detect: if no saved preference, check `navigator.language` — 'tr' → TRY, others → EUR
2. Create `src/services/fxRateService.ts`:
   - `fetchDailyRates()` — fetches from ECB API (https://api.exchangerate.host/latest?base=TRY or similar free API)
   - `cacheRates(rates)` — writes to Firestore `fxRates/TRY` document: `{ rates: { EUR: 0.0xx, ... }, updatedAt: timestamp }`
   - `getCachedRates()` — reads from Firestore `fxRates/TRY` document
   - `getEurRate(): number` — returns cached EUR/TRY rate (TRY→EUR conversion factor)
3. Add `CurrencyProvider` to `App.tsx` provider hierarchy (after LanguageProvider, before Router).
</action>

<acceptance_criteria>

- CurrencyContext exports `useCurrency()` hook returning { currency, rates, toggleCurrency, convertPrice, formatPrice }
- `convertPrice(100)` with EUR active returns display value = 100 \* EUR_RATE
- `formatPrice(1234.56, 'TRY')` returns "1.234,56 ₺"
- `formatPrice(12.34, 'EUR')` returns "€12,34"
- Currency preference persists in localStorage
- Geo-detection: Turkish browser → TRY, others → EUR
- CurrencyProvider appears in App.tsx provider chain
- fxRateService caches to Firestore `fxRates/TRY`
- `tsc --noEmit` passes
  </acceptance_criteria>

### Task 2: Add Currency Toggle and Per-Country Routing

<objective>
Add EUR/TRY toggle to Navbar, wire currency display in product prices, and set up /tr and /en URL prefixes for default currency routing.
</objective>

<read_first>

- src/components/layout/Navbar.tsx (existing navbar structure)
- src/components/commerce/ProductCard.tsx (price display)
- src/pages/ProductDetail.tsx (price display)
- src/App.tsx (router config)
  </read_first>

<action>
1. Add currency toggle to Navbar: "₺ | €" button group next to language selector.
2. Update ProductCard and ProductDetail to use `useCurrency().convertPrice()` for price display:
   - Show converted EUR price when EUR active, base TRY price when TRY
   - Show both prices on hover (EUR as secondary)
3. Set up URL routing in App.tsx:
   - `/tr/*` → default currency = TRY, language = tr
   - `/en/*` → default currency = EUR, language = en
   - Existing routes work without prefix (detect from browser)
4. Create `src/services/fxRateService.ts` server-side counterpart `server/routes/fxRates.ts`:
   - GET /api/fx-rates — returns cached rates (public, cached 1h)
   - POST /api/fx-rates/refresh — triggers fresh ECB fetch (cron, verifyCronSecret)
</action>

<acceptance_criteria>

- Navbar has TRY/EUR toggle button group
- ProductCard shows converted price: original TRY in small gray, converted in active currency
- ProductDetail shows price in active currency with secondary currency below
- `/en/product/123` defaults to EUR + English
- `/tr` defaults to TRY + Turkish
- GET /api/fx-rates returns { rates: { EUR: number }, updatedAt: string }
- POST /api/fx-rates/refresh requires cron secret
- `tsc --noEmit` passes
  </acceptance_criteria>
