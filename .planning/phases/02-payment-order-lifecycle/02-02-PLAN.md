| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-005 | Spoofing | Webhook dedup | mitigate | processedWebhooks collection with eventId check in atomic transaction (D-07/D-08); return 200 if already processed |
| T-02-006 | Tampering | SubOrder transition | mitigate | verifyFirebaseToken + seller ownership check; transitionEngine enforces valid state changes |
| T-02-007 | Elevation of Privilege | Stock manipulation | mitigate | Stock mutation only via server-side reserveStock/restoreStock using Firestore transactions with available check |
| T-02-008 | Information Disclosure | orderSet userId leak | mitigate | GET /api/orders/:orderSetId has ownership check (implemented in Phase 1) |
| T-02-009 | Repudiation | Stock overselling | mitigate | Atomic transaction with `stock.available >= quantity` guard; FieldValue.increment for concurrent safety |
