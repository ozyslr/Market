## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> API finance endpoints | Unauthenticated or unauthorized access to financial data |
| Server -> iyzico API | approval.create call to release escrow |
| Seller -> finance dashboard | Seller can only see own financial data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-014 | Information Disclosure | Finance API | mitigate | Server API only — no client Firestore access to ledger (Anti-Pattern 4). verifyFirebaseToken + sellerId ownership check on all endpoints |
| T-02-015 | Elevation of Privilege | Payout override | mitigate | verifyAdmin on POST /api/admin/manual-payout; verifyCronSecret on POST /api/process-scheduled-payouts |
| T-02-016 | Tampering | Payout amounts | mitigate | Payout amounts calculated server-side from immutable ledger entries; no client-provided amounts |
| T-02-017 | Repudiation | Payout execution | mitigate | Every payout recorded in immutable ledger with type 'payout', amount, hash chain |
</threat_model>
