## Trust Boundaries

| Boundary                        | Description                                                                                                                   |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| browser → Typesense Cloud       | Search-only key; read-only access; acceptable exposure per D-02                                                               |
| browser → POST /api/search/sync | Firebase ID token in Authorization header; server verifies ownership                                                          |
| searchTypesense() filter_by     | Built from typed SearchParams fields server-side-equivalent; raw user input never directly concatenated into filter_by string |

## STRIDE Threat Register

| Threat ID | Category               | Component                                       | Disposition | Mitigation Plan                                                                                                                                                     |
| --------- | ---------------------- | ----------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-04-08   | Tampering              | filter_by injection in searchService.ts         | mitigate    | filter_by is built from individual typed SearchParams fields using string templates; no raw user query string is placed in filter_by (query goes to 'q' param only) |
| T-04-09   | Information Disclosure | VITE_TYPESENSE_SEARCH_API_KEY in browser bundle | accept      | Key is intentionally browser-visible; scoped to documents:search only; no write/admin access per D-02                                                               |
| T-04-10   | Denial of Service      | searchTypesense() repeated retries on failure   | accept      | Single attempt per query; falls back immediately on error; no retry loop                                                                                            |
| T-04-11   | Elevation of Privilege | notifySearchSync called without auth token      | mitigate    | Early return if getAuth().currentUser is null; server also verifies token — double guard                                                                            |

</threat_model>
