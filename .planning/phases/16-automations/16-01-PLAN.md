# Plan 16-01: Automations — Invoices, Emails, E-Fatura, Abandoned Cart

**Objective:** Auto invoice PDF generation, transactional emails, e-fatura integration, and abandoned cart recovery series.

**Requirements:** AUT-01, AUT-02, AUT-03, AUT-04, AUT-05

## Tasks

### Task 1: Auto Invoice PDF (AUT-01)

- Wire invoiceService.generateCommercialInvoice into order completion flow
- Save invoice PDF URL to order document
- Add "Download Invoice" button to OrderDetail

### Task 2: Transactional Emails (AUT-02, AUT-03)

- Install nodemailer
- Create emailService with sendOrderConfirmation, sendShippingUpdate, sendSellerApproval
- Templates: order confirmed, shipped, delivered, seller approved/rejected

### Task 3: Abandoned Cart Recovery (AUT-05)

- Create abandoned cart email series (1h, 24h, 72h)
- Check for carts with no activity >1h in Firestore
- Send recovery email with cart items + checkout link

### Task 4: E-Fatura (AUT-04)

- Document Paraşüt/Logo API integration path
- Create eFaturaService stub ready for API key config
