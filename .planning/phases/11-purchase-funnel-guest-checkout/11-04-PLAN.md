## Trust Boundaries

| Boundary                    | Description                                                                     |
| --------------------------- | ------------------------------------------------------------------------------- |
| Client→Firestore events     | Funnel events written client-side to events collection; read by admin dashboard |
| Admin page→Firestore events | Admin dashboard reads events collection; requires admin auth                    |

## STRIDE Threat Register

| Threat ID | Category               | Component                | Disposition | Mitigation Plan                                                                                                                                    |
| --------- | ---------------------- | ------------------------ | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-11-11   | Information Disclosure | Funnel event data        | mitigate    | Events collection already has Firestore rules (events: create if signedIn, read if admin). Funnel events inherit this.                             |
| T-11-12   | Tampering              | Client-side event firing | accept      | Events are non-critical analytics; tampered events produce bad dashboards but no functional impact. Server-side order data is the source of truth. |
| T-11-13   | Denial of Service      | events collection growth | accept      | Each checkout produces ~5 events. With current scale, growth is negligible. Monitor collection size; add TTL policy if needed at scale.            |

</threat_model>
