## Trust Boundaries

| Boundary              | Description                                                                                               |
| --------------------- | --------------------------------------------------------------------------------------------------------- |
| Client→Firestore      | Address data written via userService; only authenticated users can save (addAddress requires userId)      |
| Browser autofill↔Form | Autocomplete attributes prompt browser to fill; no sensitive data risk (user already sees their own data) |

## STRIDE Threat Register

| Threat ID | Category               | Component           | Disposition | Mitigation Plan                                                                                                                |
| --------- | ---------------------- | ------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| T-11-05   | Information Disclosure | Browser autofill    | accept      | Autocomplete attributes only trigger on user's device; no cross-origin leakage. Standard e-commerce practice.                  |
| T-11-06   | Tampering              | addressType toggle  | accept      | Type field is cosmetic/labeling only; no authz decision. Tampered type has no security impact.                                 |
| T-11-07   | Denial of Service      | MAX_ADDRESSES limit | mitigate    | Static limit of 6 enforced client-side before Firestore write; server-side limit enforced by array size in Firestore user doc. |

</threat_model>
