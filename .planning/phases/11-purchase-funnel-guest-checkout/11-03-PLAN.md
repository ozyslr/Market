## Trust Boundaries

| Boundary                 | Description                                                                                                 |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- |
| Browser→Stripe           | Payment Request API communicates with Stripe directly for tokenization; card details never touch our server |
| Stripe→Server webhook    | payment_intent.succeeded webhook for express wallets follows the same trust path as card payments           |
| Client HTTPS requirement | Payment Request API only works on HTTPS; dev testing limited to production/staging deploy                   |
