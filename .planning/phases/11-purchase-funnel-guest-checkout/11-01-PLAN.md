<threat_model>

## Trust Boundaries

| Boundary                | Description                                                                                                     |
| ----------------------- | --------------------------------------------------------------------------------------------------------------- |
| Client→localStorage     | Cart data stored client-side; tamperable but low-risk (prices validated server-side at payment intent creation) |
| Anonymous→Authenticated | Cart merge crosses trust boundary; Firestore data takes priority                                                |
| Guest email→createOrder | Unverified email from guest; used for order confirmation only (no account created until explicit upgrade)       |

## STRIDE Threat Register

| Threat ID | Category    | Component                   | Disposition | Mitigation Plan                                                                                                                                     |
| --------- | ----------- | --------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-11-01   | Tampering   | localStorage cart           | accept      | Cart items are client-supplied; prices validated server-side via Stripe payment intent. Tampered quantities/IDs only affect what the user pays for. |
| T-11-02   | Spoofing    | guestEmail field            | mitigate    | Basic email format validation on client; order confirmation sent to this email but no auth decision based on it.                                    |
| T-11-03   | Elevation   | upgradeAnonymousAccount     | mitigate    | Firebase linkWithCredential requires valid email+password credential; email uniqueness enforced by Firebase Auth.                                   |
| T-11-04   | Repudiation | Guest order without account | accept      | Guest orders tied to Firebase anonymous UID + email; traceable. No higher risk than any e-commerce guest checkout pattern.                          |

</threat_model>
