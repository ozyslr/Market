| Threat ID | Category               | Component                              | Disposition | Mitigation Plan                                                                                              |
| --------- | ---------------------- | -------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------ |

| T-07-11   | Spoofing               | forged sellerId on the question        | mitigate    | sellerId denormalized from products/{productId} at ask time, not client-chosen for answer authorization      |
| T-07-12   | Information Disclosure | seller email/PII exposure              | mitigate    | Email resolution + send happen server-side via notify endpoint; client never receives the seller email       |
| T-07-13   | Denial of Service      | notification failure blocking question | accept      | Notification calls are fire-and-forget; question write is the source of truth and completes independently    |
| T-07-SC   | Tampering              | npm installs                           | mitigate    | No new package introduced (reuses Resend/emailService). Any new install requires audit + blocking checkpoint |
