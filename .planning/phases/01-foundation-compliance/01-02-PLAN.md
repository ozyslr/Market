      interface CommissionRule {
        ruleId: string;
        type: 'category' | 'seller' | 'global';

        rate: number;          // e.g., 0.05 = 5%
        minCommission: number; // in kurus (500 = 5 TL)

        maxApplied: boolean;

      }

      ```
      interface LedgerEntry {
        entryId: string;
        orderSetId: string;
        subOrderId: string;
        sellerId: string;
        type: 'order_charge' | 'commission' | 'payout' | 'refund' | 'adjustment';
        amount: number;          // in kurus, positive or negative
        currency: string;
        previousHash: string;    // SHA-256 of previous entry
        hash: string;            // SHA-256 of this entry's data
        reference: string;       // optional: Stripe transfer ID, etc.
        reason: string;
        createdBy: 'system' | 'admin';
        createdAt: string;
      }
      ```
    - Export `async function recordEntry(adminDb, entry: Omit<LedgerEntry, 'entryId' | 'hash' | 'previousHash' | 'createdAt'>): Promise<LedgerEntry>`
      - Use adminDb.runTransaction:
        1. Query the latest entry in ledger collection (orderBy createdAt desc, limit 1)
        2. Compute previousHash: SHA-256 of previous entry's data (or empty string for first entry)
        3. Compute hash: SHA-256 of (previousHash + JSON.stringify(entryData))
        4. Create new entry document
      - Use Node.js crypto.createHash('sha256') for hashing
      - Entry data for hash includes: orderSetId, subOrderId, sellerId, type, amount, currency, previousHash
      - Return full entry
    - Export `async function getEntriesByOrder(adminDb, orderSetId: string): Promise<LedgerEntry[]>`
      - Query ledger collection where orderSetId == orderSetId, ordered by createdAt
    - Export `async function getEntriesBySeller(adminDb, sellerId: string): Promise<LedgerEntry[]>`
      - Query where sellerId == sellerId, ordered by createdAt
    - Export `async function verifyChain(adminDb): Promise<{ valid: boolean; firstEntryId: string; lastEntryId: string; entriesChecked: number }>`
      - Read all entries ordered by createdAt
      - Recompute hash for each entry and compare to stored hash
      - Verify previousHash chain links
      - Return verification result

<threat_model>

## Trust Boundaries

| Boundary                  | Description                                     |
| ------------------------- | ----------------------------------------------- |
| client -> commission API  | Untrusted parameters for commission calculation |
| admin -> commission rules | Admin creates/modifies rate rules (high impact) |
| server -> ledger          | Append-only writes with hash chain integrity    |

## STRIDE Threat Register

| Threat ID | Category               | Component                     | Disposition | Mitigation Plan                                                                                                          |
| --------- | ---------------------- | ----------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------ |
| T-01-006  | Tampering              | commission rule rates         | mitigate    | verifyAdmin middleware on all rule CRUD; admin-only writes                                                               |
| T-01-007  | Tampering              | ledger entries                | mitigate    | append-only Firestore rules (no update/delete). Hash chain detects post-write tampering. verifyChain endpoint for audit. |
| T-01-008  | Repudiation            | commission calculation        | mitigate    | every calculation recorded as ledger entry with hash chain; verifyChain proves integrity                                 |
| T-01-009  | Information Disclosure | GET /api/ledger/order/:id     | mitigate    | ownership check before returning seller financial data                                                                   |
| T-01-010  | Elevation of Privilege | direct Firestore ledger write | mitigate    | firestore.rules: create=false on ledger collection (server SDK only)                                                     |

</threat_model>
