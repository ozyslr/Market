## Trust Boundaries

| Boundary                                             | Description                                                     |
| ---------------------------------------------------- | --------------------------------------------------------------- |
| Buyer browser → POST /api/orders/.../return-request  | Authenticated buyer; must own the OrderSet                      |
| Seller/admin browser → POST /api/returns/:id/approve | Authenticated; must own the return (sellerId match) or be admin |
| Seller/admin browser → POST /api/returns/:id/reject  | Same as approve                                                 |

## STRIDE Threat Register

| Threat ID  | Category               | Component                                              | Disposition | Mitigation Plan                                                                                            |
| ---------- | ---------------------- | ------------------------------------------------------ | ----------- | ---------------------------------------------------------------------------------------------------------- |
| T-05-04-01 | Elevation of Privilege | Buyer creates return on another buyer's order          | mitigate    | orderSet.userId === req.uid check before creating return doc; return 403 if mismatch                       |
| T-05-04-02 | Elevation of Privilege | Seller approves another seller's return                | mitigate    | returns/{id}.sellerId === req.uid OR req.isAdmin; return 403 if neither                                    |
| T-05-04-03 | Tampering              | Return window bypass (client sends forged deliveredAt) | mitigate    | Server reads deliveredAt from Firestore (SubOrder doc), never from request body; client cannot forge it    |
| T-05-04-04 | Tampering              | Double-approval (approve called twice)                 | mitigate    | status === 'pending' guard before approval; second call returns 409                                        |
| T-05-04-05 | Denial of Service      | processRefund called with wrong subOrderId             | mitigate    | Return doc stores subOrderId at creation time from verified SubOrder doc load; not taken from request body |
| T-05-SC    | Tampering              | npm installs                                           | accept      | No new packages; crypto.randomUUID() is Node built-in                                                      |

</threat_model>
