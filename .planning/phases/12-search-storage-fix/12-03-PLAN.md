# Plan 12-03: Typesense Search UI & Faceted Filtering

**Objective:** Build the client-side search UI with typo-tolerant full-text search, as-you-type results, and faceted filtering (category, price range, brand, rating).

**Requirements:** SRC-02

## Tasks

### Task 1: Create Search UI Components

<objective>
Replace the current Firestore-based search with Typesense-powered InstantSearch UI components: SearchBar with autocomplete, SearchResults grid, and FacetedFilters sidebar.
</objective>

<read_first>

- src/pages/Home.tsx (current search implementation)
- src/services/searchService.ts (current search service)
- src/services/typesenseService.ts (created in 12-02)
- src/components/ (existing component patterns — read ProductCard.tsx for result card pattern)
  </read_first>

<action>
1. Install `typesense-instantsearch-adapter` npm package.
2. Create `src/components/search/SearchBar.tsx`:
   - Input with search icon, clear button, and loading spinner
   - As-you-type search (debounced 300ms) via Typesense
   - Autocomplete dropdown showing top 5 product matches (title + price + image thumbnail)
   - Keyboard navigation (arrow keys + enter) in dropdown
   - Mobile: full-width, collapsible on focus/blur
   - RTL support for Arabic
3. Create `src/components/search/SearchResults.tsx`:
   - Grid layout matching existing ProductCard grid
   - Shows result count: "X ürün bulundu" (TR) / "X products found" (other locales)
   - Empty state: "Aramanızla eşleşen ürün bulunamadı. Farklı anahtar kelimeler deneyin."
   - Highlights matching text in product titles (bold/em tags)
   - Infinite scroll or "Load more" pagination (page size: 24)
4. Create `src/components/search/FacetedFilters.tsx`:
   - Category filter: checkbox list from Typesense facet counts
   - Price range: dual slider (min-max) with TRY/EUR-aware formatting
   - Brand filter: searchable checkbox list (if more than 10 brands)
   - Rating filter: star rating buttons (4+, 3+, 2+, 1+)
   - Mobile: slide-out drawer or bottom sheet
   - "Clear all filters" button
   - Each filter shows result count in parentheses
5. Create `src/services/searchService.ts` (update existing):
   - Replace Firestore queries with typesenseService.searchProducts()
   - Handle multi-language: detect active language → search correct collection
   - Build Typesense search parameters from filter state
   - Cache recent searches in sessionStorage for instant back-navigation
</action>

<acceptance_criteria>

- SearchBar shows autocomplete dropdown with top 5 matches including thumbnail
- As-you-type search fires after 300ms debounce
- SearchResults shows product grid with match highlighting in titles
- Empty state message shown when zero results
- FacetedFilters has: category checkboxes, price range slider, brand filter, rating filter
- Each filter option shows result count
- Mobile: filters open in bottom sheet / slide-out drawer
- "Clear all filters" resets all filters to default
- `typesense-instantsearch-adapter` appears in package.json
- RTL layout works for Arabic
- `tsc --noEmit` passes
  </acceptance_criteria>
