# Requirements: Benim Olan (Mercora) — v5.0 "Merchant Dashboard"

**Defined:** 2026-06-07 | **Milestone:** v5.0

## v5.0 Requirements

### Satıcı Panel UI (DUI)

- [ ] **DUI-01**: Drag-drop içerik blok editörü — satıcı mağaza sayfası bloklarını görsel olarak yönetir
- [ ] **DUI-02**: Satıcı menü yönetimi UI — kategori menüsü oluşturma, düzenleme, sıralama arayüzü
- [ ] **DUI-03**: Kupon yönetimi UI — kupon oluşturma, listeleme, düzenleme, durdurma arayüzü

### Satıcı Analitiği (SAN)

- [ ] **SAN-01**: Mağaza ziyaret istatistikleri — günlük ziyaret, sayfa görüntüleme, tekil ziyaretçi
- [ ] **SAN-02**: Satış dönüşüm hunisi — ziyaret → sepete ekleme → satın alma oranları
- [ ] **SAN-03**: Ürün performansı — en çok satanlar, en çok görüntülenenler, düşük performanslılar

### Dinamik Fiyatlandırma (DPR)

- [ ] **DPR-01**: Rakip fiyat takibi — aynı kategorideki benzer ürünlerin fiyat karşılaştırması
- [ ] **DPR-02**: Otomatik fiyat güncelleme — rakip fiyatına göre otomatik marj ayarı
- [ ] **DPR-03**: Fiyat geçmişi ve trend grafiği

### WMS / Depo Yönetimi (WMS)

- [ ] **WMS-01**: Stok konumu takibi — ürünlerin depo/raf konumu
- [ ] **WMS-02**: Stok hareket logu — giriş/çıkış/transfer kaydı
- [ ] **WMS-03**: Düşük stok uyarısı — eşik değer altında otomatik bildirim
