## Bölüm 1: Kayıt & KYC — %85 Tamam

### ✅ Çalışanlar

- 3 adımlı satıcı başvuru formu (mağaza bilgisi → belge yükleme → onay)
- 3 belge zorunluluğu (kimlik, vergi, banka IBAN)
- Firebase Storage'a KYC belge yükleme
- Stripe Identity otomatik kimlik doğrulama
- Admin KYC onay/red paneli (AdminSellers + AdminSellerView)
- EU: Stripe Connect Express otomatik provizyon
- TR: Iyzico sub-merchant provizyon
- Satıcı paneli guard: 5 durum (loading/none/pending/rejected/verified)

### 🟡 Eksikler

- Mağaza bilgisi form alanlarında client-side validasyon yok (boş gönderilebiliyor)

## Bölüm 2: Ürün Yönetimi — %60 Tamam

### ✅ Çalışanlar

- 30+ alanlı ürün formu (başlık, marka, SKU, kategori, fiyat, stok, GPSR uyumluluğu)
- AI destekli içerik üretimi (Gemini: açıklama, meta, görsel)
- Sürükle-bırak görsel yükleme (Firebase Storage)
- **Toplu CSV ithalat:** PapaParse + sunucu-taraflı Zod validasyonu, SSRF-korumalı URL'den görsel çekme
- XML feed ithalat + AI alan eşleştirme
- İthalat hata raporu (satır, alan, sebep)
- Ürün moderasyon akışı: draft → pending → approved/rejected
- Toplu ürün düzenleme (fiyat/stok)
- Ürün kopyalama, silme (tekli/toplu)

### 🟡 Eksikler

- **Varyant yönetimi UI'ı YOK** — `ProductVariant` tipi var ama formda varyant ekleme arayüzü yok
- **Toplu durum güncelleme stub** — `handleBulkStatusUpdate` sadece `alert()` gösteriyor
- **Stok hareket geçmişi yok** — stok sadece integer, kim/ne zaman değiştirdi belli değil
- **Düşük stok uyarısı yok** — `SellerInventory` analytics sekmesi placeholder
- **SEO sınırlı** — sadece `metaDescription`, `metaTitle`/`metaKeywords`/`ogImage` yok

### 🔴 Eksikler

- **Hazır platform konnektörleri yok** — Shopify/WooCommerce/Trendyol API entegrasyonu yok
- **Çoklu depo (multi-warehouse) yok**

## Bölüm 3: Sipariş & Ödeme — %65 Tamam

### ✅ Çalışanlar

- Gerçek zamanlı sipariş takibi (Firestore onSnapshot)
- Sipariş filtreleme (durum, arama), kargo takip numarası girişi
- 7 kargo firması seçeneği (PTT, Yurtiçi, Aras, MNG, Surat, UPS, DHL)
- Toplu kargolama (BatchShipModal)
- İade yönetimi (ReturnManagementSection)
- Otomatik fatura oluşturma
- Satıcı finans paneli: bakiye, bekleyen, toplam kazanç, işlem geçmişi
- Komisyon sistemi: çift katmanlı (satıcı override > kategori override > global)
- Immutable hash-chain ledger
- T+7 toplu ödeme altyapısı (Pazartesi 03:00 cron)

### 🟡 Eksikler

- **Kargo firmaları MOCK** — `cargoService.ts` tüm kargo API'leri simülasyon
- **Gerçek para transferi YOK** — `processPayout` sadece ledger günceller, Stripe Transfer çağrısı yapmıyor
- **E-fatura GIB bağlantısı MOCK** — UBL-TR XML formatı doğru ama GIB API simülasyon
- **Satıcı banka hesabı/IBAN yönetim UI'ı yok**

## Bölüm 4: Mağaza & Admin — %70 Tamam

### ✅ Çalışanlar

- Mağaza özelleştirme: logo, banner, renk, sosyal linkler, açıklama
- Kupon yönetimi: yüzde/sabit, min sepet, kullanım limiti, son kullanma
- Herkese açık mağaza sayfası: ürün listesi, filtreleme, arama, değerlendirmeler
- Admin: KYC onay/red, komisyon oranı, satıcı askıya alma
- Admin: Ürün moderasyonu (onayla/reddet/değişiklik iste)
- Satıcı tier sistemi (5 seviye: Starter/Bronze/Silver/Gold/Platinum)

### 🟡 Eksikler

- **Admin Dashboard:** Hata durumunda mock fallback'e düşüyor
- **Satıcı tier'ları UI'a bağlanmamış** — servis var ama admin/satıcı panelinde tier yönetimi yok
- **Satıcı API:** Webhook desteği yok

### 🔴 Eksikler

- **AdminFinance.tsx** — Tamamen yok (ödeme/finans admin paneli)
- **AdminReports.tsx** — Tamamen yok (raporlama admin paneli)
