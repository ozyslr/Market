# Milestone v4.0: Seller Empire

**Status:** ✅ SHIPPED 2026-06-07
**Phases:** 22–25
**Total Plans:** 4

## Overview
Give sellers full control over their store page — customizable storefront with banner/logo/branding, drag-and-drop content blocks (flash products, trending, campaigns, categories, promos), custom menu navigation, and coupon/discount management. Each seller builds their own mini e-commerce site.

## Phases

### Phase 22: Seller Store Management
**Goal:** Seller can customize store from dashboard — banner, logo, name, description, brand color, social links, live preview.
**Plans:** 1 — SellerStoreSettings page + sellerStoreService

### Phase 23: Store Content Blocks
**Goal:** 6 block types for seller store layout — flash products, trending, campaign banner, category cards, promo banner, product grid.
**Plans:** 1 — storeContentService with Firestore persistence

### Phase 24: Seller Menu Management
**Goal:** Seller creates custom menu with categories, sub-menus, images, and ordering.
**Plans:** 1 — sellerMenuService with nested menu items

### Phase 25: Seller Coupons & Discounts
**Goal:** Seller creates coupons — percentage/fixed discount, minimum order, expiry, product-specific, validation at checkout.
**Plans:** 1 — sellerCouponService with CRUD + validation

## Key Accomplishments
1. Seller store settings dashboard with banner/logo upload, brand color picker, social links
2. Content block system: flash products, trending, campaigns, categories, promos, product grid
3. Custom seller menu navigation with nested items and image support
4. Coupon system: percentage/fixed discount, min order, expiry, product-specific, checkout validation

## Key Decisions
- Store config stored in Firestore `storeConfigs/{sellerId}` document
- Content blocks stored in `storeContentBlocks/{sellerId}` with 6 default blocks
- Seller menus stored in `sellerMenus/{sellerId}` with default menu items
- Coupons stored in `sellerCoupons` collection with validation at checkout
- All seller customization uses Firestore merge strategy (preserves existing data)
