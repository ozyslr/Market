  - Real-time trending calculation (last 24 hours)
  - "Trending Now" carousel with sales velocity

  - ML-driven homepage customization per user session
  - "Recommended For You" section (persistent)

  - Sticky header positioning on scroll

- **Advanced Filtering System**

  - Cart sync across devices

### Checkout Flow (Multi-Step)

#### Step 1: Shipping Address
- **Address Selection/Entry**
  - List of saved addresses (radio buttons)
  - "Use a new address" option
  - Address form fields:
    - Full name
    - Phone number
    - Region/Province dropdown
    - City dropdown
    - Neighborhood
    - Street address
    - Building number/Apt number
    - Postal code
    - Address type (home, office, other)
    - Set as default address checkbox

- **Address Validation**
  - Postal code validation against database
  - Autocomplete for district/neighborhood
  - Map preview of address location (optional)

- **Delivery Option Selection per Seller**
  - Same-day delivery (if available)
  - Next-day delivery
  - Standard delivery (3-7 business days)
  - In-store pickup (if applicable)
  - Estimated delivery date displayed
  - Shipping cost per option
  - Free shipping eligibility indicator

- **Multiple Addresses for Multiple Sellers**
  - Different sellers can ship to different addresses
  - Address selector per seller group
  - Consolidation options (if same address chosen)

#### Step 2: Shipping Method & Confirmation
- **Shipping Method Review**
  - Selected address confirmation
  - Delivery method per seller
  - Estimated delivery date
  - Shipping cost breakdown
  - "Change address" / "Change delivery method" links

#### Step 3: Payment Method Selection
- **Payment Options**
  - Credit/Debit card (Visa, Mastercard, American Express)
  - Debit card (domestic)
  - Turkish bank transfer
  - PayPal
  - Apple Pay
  - Google Pay

- **Card Payment Form**
  - Card number field (PCI-DSS compliant, masked)
  - Expiration date (MM/YY)
  - CVV/CVC
  - Cardholder name
  - Billing address (auto-filled or editable)
  - "Save this card for future purchases" checkbox

- **Installment Options**
  - Available on credit cards
  - 2, 3, 4, 6, 9, 12 month options (varies by bank)
  - Installment cost breakdown
  - APR/interest displayed
  - Zero-interest options promoted
  - Bank-specific promotions shown

- **Digital Wallet Integration**
  - Apple Pay (one-click payment)
  - Google Pay (one-click payment)
  - PayPal integration (separate login)

- **Payment Security Badges**
  - SSL certificate indicator
  - 3D Secure (3DS) authentication
  - PCI DSS compliance badge
  - Trust seals (if applicable)

#### Step 4: Coupon & Promotional Code Entry
- **Coupon Input**
  - Second chance to enter coupon code
  - "Promo Code" input field
  - "Apply" button
  - Previous coupon display

- **Coupon Types Supported**
  - Platform-wide coupons (percentage or fixed amount)
  - Category-specific coupons
  - Seller-specific coupons
  - First-time buyer coupons
  - Free shipping coupons
  - Bundle coupons
  - Referral coupons

- **Coupon Validity Rules**
  - Minimum order amount requirements
  - Maximum discount cap
  - Applicable product categories
  - Excluded products
  - Validity date range
  - User eligibility (first-time, loyalty tier, etc.)

#### Step 5: Order Review & Confirmation
- **Order Summary**
  - Item list (name, quantity, price)
  - Shipping address (formatted clearly)
  - Shipping method and estimated delivery
  - Payment method (card last 4 digits, type)
  - Subtotal
  - Shipping cost(s)
  - Discounts applied
  - Tax (if applicable)
  - Final total (large, bold)

- **Terms & Conditions**
  - Checkbox for accepting T&C
  - Link to full terms
  - Privacy policy link
  - Return policy acknowledgment

- **Complete Purchase Button**
  - Large, prominent CTA button
  - "Place Order" or "Confirm Purchase" text
  - Loading state during processing
  - Disabled until all required fields filled

### Post-Purchase
