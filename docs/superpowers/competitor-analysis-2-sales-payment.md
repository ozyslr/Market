# Rakip Analizi - Satis Yontemleri ve Odeme Surecleri

**Tarih:** 21 Mayis 2026
**Analiz Yapan:** Ajan 2/8
**Rakipler:** Etsy, Amazon Handmade, Trendyol

## 1. Etsy — Satis Yontemi Ozeti

### Checkout Akisi
- **3 ana adim:** Sepet → Teslimat/Adres → Odeme
- Etsy hesabi zorunlu DEGIL (misafir checkout var)
- Sepette "Save for later" ozelligi
- Checkout sayfasi tek sayfada adres ve odeme (scroll-based)

### Odeme Yontemleri
| Yontem | Durum |
|---|---|
| Kredi/Banka Karti (Visa, MC, Amex, Discover) | Var |
| PayPal | Var |
| Apple Pay | Var |
| Google Pay | Var |
| Klarna (Buy Now Pay Later) | ABD, UK, AB'de var |
| Afterpay/Clearpay (taksit) | ABD, UK, AU'da var |
| Etsy Gift Card / Etsy Credit | Var |
| iDEAL (Hollanda) | Var |
| Sofort (AB) | Var |

### Taksit / BNPL
- Klarna: 4 taksit (ABD/UK) veya 30 gun sonra odeme
- Afterpay/Clearpay: 4 taksit, 2 haftada bir
- Kredi karti taksit: Etsy dogrudan taksit sunmaz, bankaya bagli

### Misafir Alisverisi
- **Evet,** misafir checkout destekleniyor
- Siparis takibi icin email + siparis kodu yeterli
- Hesap olusturma opsiyonel (checkout sonrasi tesvik edilir)

### Sepet Kurtarma
- Email hatirlatmalari (terk edilmis sepet)
- Push notification (mobil)
- "Items in your cart are selling fast" turu aciliyet mesajlari
- Indirim kuponu bazen tetiklenir (stoka bagli)

### Mobil Odeme Deneyimi
- Mobil web + native app
- Apple Pay / Google Pay tek dokunus
- Klarna/Afterpay mobilde sorunsuz

### Siparis Takip ve Bildirim
- /orders sayfasi: gecmis siparisler
- Email: her adimda bildirim (siparis alindi, kargoda, teslim)
- Push notification (mobil)
- Kargo takip no dogrudan sayfada
- Satirciya mesaj gonderme (conversations)

## 2. Amazon Handmade — Satis Yontemi Ozeti

### Checkout Akisi (Amazon Altyapisi)
- **1 adim (1-Click):** Kayitli kullanicilar icin tek tikla siparis
- **2 adim (normal):** Sepet → Amazon hesabi girisi → Teslimat adresi secimi → Odeme secimi → Siparisi onayla
- Amazon hesabi ZORUNLU (misafir checkout YOK)
- Amazon Pay: harici sitelerde de kullanilabilir

### Odeme Yontemleri
| Yontem | Durum |
|---|---|
| Kredi/Banka Karti (Visa, MC, Amex, Discover) | Var |
| Amazon Gift Card | Var |
| Amazon Store Card | Var |
| Amazon Points (kredi karti puan) | Var |
| Banka Hesabi (direkt debi, ABD) | Var |
| PayPal (SADECE AB disi sitelerde) | Sinirli |
| Klarna/Afterpay | Amazon'da yok (ABD'de Affirm ile pilot) |

### Taksit / BNPL
- Amazon Monthly Payments: 5-12 ay taksit (belirli urunlerde)
- Amazon Store Card: ozel finansman
- Affirm (pilot, ABD): 3-24 ay
- Amazon Handmade'de taksit secenegi KISITLI

### Misafir Alisverisi
- **Yok.** Amazon hesabi olmak zorunlu
- Bu Handmade icin de ayni

### Sepet Kurtarma
- Amazon nadiren indirim kuponu gonderir
- Email: "You left something in your cart"
- Mobile push notification
- Alexa hatirlatici
- Prime uyelik terk oranini ciddi dusurur

### Kargo ve Teslimat (Prime Entegrasyonu)
- Amazon Handmade = Amazon Logistics altyapisi
- Prime kargo: 2 gun teslimat (uygun urunlerde)
- Amazon Locker: guvenli teslimat noktasi
- Amazon Hub: teslimat noktalari
- Same-Day Delivery: secili bolgelerde

### Siparis Takip ve Bildirim
- Amazon hesabi / mobil uygulama
- Harita uzerinde canli kargo takibi (son 3 durak)
- Amazon "Track Package" sayfasi
- Email + push notification (her adim)
- Amazon Hub / Locker teslimat bildirimi

## 3. Trendyol — Satis Yontemi Ozeti

### Checkout Akisi
- **4-5 adim:** Sepet → Teslimat adresi → Kargo teslim tipi → Odeme → Siparis onay
- Trendyol hesabi gerekli (kayit zorunlu)
- Hizli kayit: Google/Apple ile oturum ac

### Odeme Yontemleri
| Yontem | Durum |
|---|---|
| Kredi Kartı (Visa, MC, Troy) | Var |
| Banka Kartı (debit) | Var |
| Kapıda Ödeme (kredi kartı) | Var |
| Kapıda Ödeme (nakit) | Var |
| Trendyol Cüzdan | Var |
| Trendyol Hediye Kartı | Var |
| Havale / EFT | Var (manuel) |
| Apple Pay | Var |
| Google Pay | Var |

### Taksit / BNPL
| Vade | Durum |
|---|---|
| 2-12 ay taksit | Var (secilen bankalarda) |
| 3 ay taksit | Cogunlukla standart |
| 6 ay taksit | Yaygin |
| 9-12 ay taksit | Yuksek tutarlarda |
| Taksit + para puan | Var |

### Kapida Odeme
- **Nakit:** Kuryeye nakit odeme (ek ucret: ~15-25 TL)
- **Kredi karti:** Kuryede POS cihazi ile odeme (ek ucret: ~30-40 TL)
- Kapida odede taksit secenegi de var
- Kapida iade: Kuryeye urunu teslim, para Trendyol Cuzdan'a

### Trendyol Cuzdan
- Iade paralari burada toplanir
- Sonraki alisverislerde otomatik kullanilir
- Banka kartina transfer edilebilir
- Kredi karti yukleme destegi

### Misafir Alisverisi
- **Yok.** Uyelik zorunlu
- Google/Apple hesabi ile hizli uyelik

### Sepet Kurtarma
- Itme bildirimi (mobil)
- E-posta: "Sepetinde seni bekleyen urunler var"
- SMS (izinli kullanicilara)
- Sepetteki urun fiyati duserse bildirim
- Uygulama icinde badge bildirimi

### Mobil Odeme Deneyimi
- Trendyol mobil uygulama (yerli en iyisi)
- Google Pay / Apple Pay
- Trendyol Cuzdan ile tek dokunus
- Parmak izi / yuz tanima ile odeme onayi
- Sepet sayfasindan hizli checkout

### Siparis Takip ve Bildirim
- Trendyol Go: canli harita uzerinde kurye takibi (son 1 saat)
- Status bazli timeline: Hazirlaniyor → Kargoda → Dagitima Cikti → Teslim Edildi
- Push notification: her adimda
- SMS: kargoda ve teslim aninda
- In-app: Trendyol Go sayfasi
- Kargo takip no: Tum firmalar icin (Yurtici, Aras, MNG, PTT)

## 6. Mercora icin Eksikler ve Oneriler (Oncelik Sirasiyla)

### P0 — Kritik Eksikler (Hemen Yapilmali)

1. **Misafir Checkout Destegi**
   - Mevcut durumda kontrol etmedim ama checkout `useAuth()` cagiriyor — buyuk ihtimal login zorunlu
   - Etsy'de misafir checkout cok guclu, donusum oranini artirir
   - **Oneri:** Checkout akisinda login olmayan kullaniciya misafir olarak devam et secenegi ekle, email + siparis kodu ile takip sagla

2. **Apple Pay / Google Pay Entegrasyonu**
   - Stripe bunlari native destekliyor — sadece PaymentElement'te etkinlestirmek yeterli
   - Mobil donusum orani %15-25 artar
   - **Oneri:** Stripe dashboard'dan wallet payment'lari ac, ekstra kod yok

3. **Dijital Cuzdan / Bakiye Sistemi**
   - Trendyol Cuzdan benzeri, iade paralarinin toplandigi bir cuzdan
   - Iade surecini hizlandirir, musteri bagliiligini artirir
   - **Oneri:** Firestore'da `wallet` koleksiyonu + `walletTransactions` ile basit bakiye sistemi

### P1 — Yüksek Oncelik

4. **BNPL (Buy Now Pay Later) Secenegi**
   - Etsy'de Klarna+Afterpay, Amazon'da Affirm
   - Sepet ortalamasini %20-40 artirdigi kanitlanmis
   - **Oneri:** Stripe icinden Klarna veya Afterpay'i PaymentMethodTypes'a ekle

5. **Hediye Kartı Sistemi**
   - Her 3 rakibin de var
   - Hem satis kanali, hem musteri kazanim araci
   - **Oneri:** Yeni `giftCards` koleksiyonu, checkout'ta hediye karti kod girisi, bakiye sorgulama API

6. **Kapida Odeme (COD)**
   - Trendyol'da cok yaygin (Turkiye'de musteri tercihi)
   - Guven sorunu olan musteriler icin onemli
   - **Oneri:** Sadece Turkiye bolgesinde, ek ucret karsiligi, kurye entegrasyonu ile

### P2 — Orta Oncelik

7. **PayPal Entegrasyonu**
   - Etsy'de en yaygin yontemlerden biri
   - ABD/AB musterileri icin onemli
   - **Oneri:** Stripe alternatifi olarak, /api/create-payment-intent yaninda

8. **Canli Kargo Takibi (Harita)**
   - Trendyol Go ve Amazon Track Package benzeri
   - Musteri memnuniyetini ciddi artirir
   - **Oneri:** Kargo entegrasyonu (API) ile son 3 durak harita gosterimi

9. **Sepet Kurtarma Otomasyonu**
   - Mevcut /api/abandoned-cart/check var ama email/SMS/push otomasyonu yok
   - 24 saat, 48 saat, 72 saat hatirlatma sirasi
   - **Oneri:** Firebase Cloud Functions ile otomatik email/push notification sistemi

### P3 — Dusuk Oncelek (Gelecek)

10. **1-Click Checkout**
    - Amazon'un en guclu ozelligi
    - Kayitli kredi karti + adres ile tek tik
    - **Oneri:** Cok sonra, kullanici tabani buyuyunce

11. **Abonelik / Tekrarlayan Odeme**
    - Mercora'daki urun modeline uygun degil (el yapimi nadir urunler)
    - Gelecekte dijital urunler veya premium uyelik icin
